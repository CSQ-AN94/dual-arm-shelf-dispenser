## 6. 出问题时先看这三条

### 6.1 头部相机掉线

报 `未找到 RealSense 153122071777；当前设备: ['405622073249','335522072194']`。

昨天出现 **三次，整机重启无效**。会让任何依赖头部相机的步骤随机失败。
**先换 USB 口试试**；跑之前可以先确认相机在不在：

```bash
"'
```

看到 `153122071777` 才是好的。

### 6.2 关节报 0xF000（通信丢帧）

**拖动示教之后很常见**——按住绿色拖动按钮会把这个标志锁住。
现在预检会自动尝试清除（条件很窄，清完还要连续两次复读干净），
所以一般不用管。如果它拦住了执行，重跑一次通常就好。

### 6.3 夹爪读数全 0

末端掉线。**只有给工具口断电有效，重发协议无效**。
**手里有东西时不要断电。**
